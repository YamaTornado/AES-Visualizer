1. SB – SubBytes: Each individual byte is replaced by another via a fixed table (the S-box). This works like a cipher in which each letter is swapped for another. This step makes the process non-linear, and therefore difficult to reverse.
2. SR – ShiftRows: The rows of the table are shifted. Row 1 remains in place, row 2 shifts one place to the left, row 3 shifts two places to the left and row 4 shifts three places to the left. As a result, the bytes end up in different columns.
3. MC – MixColumns: Each column is mathematically shuffled so that each byte subsequently depends on all four bytes in its column. Together with ShiftRows, this ensures that a tiny change spreads rapidly across the entire block.
4. ⊕ Kᵢ – AddRoundKey: Finally, everything is XORed with the round key Kᵢ. In bitwise terms, XOR means that matching bits result in 0, whilst different bits result in 1. This is where the secret comes into play. Anyone could verify the first three steps, but without the key, the final step cannot be reversed.
